One kind, funny fortune for the houseplant on the windowsill — a single line of 86 characters, written by a small deterministic Node program (stdlib only, no network) to `/output/entry.txt`. The fortune predicts a ladybug moving in next week, paying rent in good luck, and never once nibbling a leaf: a plant's own future, warm to plant and keeper, with a small joke that lands and the cadence of a fortune-cookie prediction.

## Run it

```sh
node main.ts
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`). The program validates the fortune itself: 1–120 characters, one line, no trailing newline.
